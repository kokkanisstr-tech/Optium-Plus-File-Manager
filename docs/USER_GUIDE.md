# Руководство пользователя

## Первый запуск

1. Запустите `OptiumPlusFileManager.exe` на Windows x64.
2. Откройте вкладку **Настройки**. Приложение создаёт входящую папку по умолчанию; добавьте нужные папки, например `Загрузки`.
3. Оставьте автосортировку выключенной, пока не проверите результаты на демонстрационных файлах.
4. На вкладке **Обзор** нажмите **Сортировать входящие**, чтобы обработать текущие файлы, либо включите **Автосортировка**.
5. Нужная папка создаётся при первом успешном перемещении. Флажок **Открывать папку назначения** открывает каждую папку только при первом попадании в неё файла за текущий запуск программы.

На вкладке **Обзор** крупные ярлыки быстрого перехода ведут к папкам C#, Python, SQL, документов, изображений, архивов и ко всем результатам. Нажмите ярлык, чтобы выбрать и раскрыть эту папку в дереве; ярлык **Все файлы** открывает папку результатов. В дереве категории, подкатегории и готовые файлы различаются увеличенными значками, а рядом с ярлыками показано число файлов. Дважды щёлкните папку или файл, чтобы открыть его; кнопка **Обновить список** перечитывает настроенную папку результатов. Изменения приложения появляются сразу, внешние изменения папок проверяются периодически. Флажок **Тёмная тема** в правом верхнем углу меняет оформление всего приложения и сохраняет выбор.

Автозапуск Windows и автосортировка — отдельные настройки. Автозапуск может открыть приложение в трее, но без включённой автосортировки новые файлы автоматически не перемещаются.

## Ежедневная работа

### Наблюдаемые папки

На вкладке **Настройки** можно добавить и удалить входящие папки и включить обход подпапок. Нельзя выбрать внутренние папки приложения или `Sorted`. Символические ссылки в путях наблюдения запрещены. При включённой автосортировке приложение отслеживает события файловой системы и раз в две минуты повторно сверяет папки, чтобы найти пропущенные события.

Кнопка **Исключения…** задаёт пути, которые нужно пропускать, и glob-маски имён файлов, например `*.tmp` или `secret-??.txt`. Маски применяются только к имени файла. Общий предел размера задаётся в мегабайтах; файлы выше предела помещаются в карантин.

Кнопка **Сортировать сейчас** обрабатывает уже существующие файлы независимо от состояния автосортировки. Временные расширения `.tmp`, `.part`, `.crdownload` и `.download` пропускаются.

### Добавление отдельных файлов

Перетащите файл в окно или нажмите **Добавить файлы**. Приложение копирует его в локальный `Inbox`, оставляя выбранный исходник нетронутым, и обрабатывает копию. Через REST и MCP входящие потоки также сначала сохраняются в `Inbox`.

Для файлов из наблюдаемой папки приложение ожидает завершения записи, затем вычисляет SHA-256. Если такой хеш уже есть в истории, новая копия получает статус `Duplicate` и остаётся на месте; программа не удаляет её автоматически.

### Поиск файлов обычными словами

Откройте вкладку **ИИ-поиск** и напишите, что помните о файле: например, `математический модуль на C#`, `SQL запросы про студентов` или `скан расписания`. Запрос можно отправить кнопкой **Найти файл** или клавишей Enter. В таблице показываются только существующие файлы; дважды щёлкните строку или выберите её и нажмите **Показать файл в папке**, чтобы открыть Проводник с выделенным файлом.

Если в запросе указан язык программирования, сначала проверяется соответствующая папка, например `Programming/CSharp`. Только если там совпадений нет, приложение ищет по остальным папкам `Sorted`. Без названия языка поиск сразу проверяет `Sorted`. Папки `Inbox`, `Review` и произвольные каталоги компьютера поиск не сканирует. Если совпадений нет, результат явно сообщает об этом.

Локальная проверка использует имена и извлечённое содержимое: код и текст, поддерживаемые PDF/Office-документы, список имён ZIP-архива, локальный OCR изображения и доступные технические поля медиафайлов. Первый поиск может занять больше времени: содержимое проверяется пакетами с ограниченным параллелизмом. Повторные запросы используют результаты чтения из ограниченного кэша, пока файл не изменился. Таблица показывает не более 100 лучших совпадений. Для типов, из которых текст безопасно извлечь нельзя, поиск может найти файл по имени, но не обещает понимать его бинарное содержимое.

При включённом облачном режиме настроенный провайдер проверяет разрешённые файлы порциями до 16 кандидатов и останавливается при найденном совпадении. Расход запросов учитывается в месячном лимите; если лимит достигнут, оставшиеся файлы всё равно проверяются локально. Передача следует настройкам разрешённых форматов, секрет-фильтру и локальным приватным папкам. Если файл был отсортирован из приватной папки, история сохраняет это ограничение и для поиска. Полный путь не отправляется. Для поиска по содержимому изображения байты PNG/JPEG/WebP отправляются только при отдельном разрешении и включённом типе, не более двух изображений за запрос. При `Off`, отсутствии подходящего ключа или ошибке провайдера используется локальный поиск.

### Очередь «На проверку»

Здесь показываются низкая уверенность, конфликт расширения и содержимого, неизвестный или повреждённый формат, а также ситуации, где извлечение не дало надёжного результата.

1. Выберите строку и посмотрите предложенную категорию, уверенность и причину.
2. В списке выберите правильную категорию.
3. Нажмите **Подтвердить и переместить**.
4. По желанию отметьте **Запомнить категорию для файлов с таким же именем**. Это создаёт локальное правило точного совпадения имени; правило хранится в базе приложения и не отправляется в облако.

Кнопка **Не сортировать** закрывает решение без перемещения файла: он остаётся в текущей папке проверки и получает статус `Skipped`. Кнопка **Показать в папке** открывает Проводник и выделяет файл, не запуская его. Повторный анализ доступен для файла в очереди проверки.

### История, повторный анализ и отмена

На вкладке **История** фильтры применяются по статусу, верхней категории, источнику и периоду. Таблица показывает последние 500 подходящих записей. Экспорт CSV выгружает все записи по текущим фильтрам постранично.

Повторный анализ доступен для завершённых файлов, очереди проверки и ошибок. Если классификация оставила файл в той же папке, повторный анализ не создаёт копию с суффиксом.

**Отменить перемещение** возвращает только завершённые, ожидающие проверки или помещённые в карантин файлы. Перед возвратом приложение сверяет сохранённый SHA-256 и проверяет, что исходное имя свободно. Для вручную добавленной копии исходный путь — путь шлюза `Inbox`; выбранный пользователем исходник не перемещался.

## Значение статусов

| Статус | Значение |
|---|---|
| `Detected`, `Ready`, `Extracting`, `Classifying` | файл проходит локальный конвейер |
| `Moving` | целевой путь сохранён в базе; операция восстанавливается после перезапуска |
| `Completed` | файл отсортирован |
| `NeedsReview` | требуется решение пользователя |
| `Skipped` | пользователь оставил файл в папке проверки без сортировки |
| `Quarantined` | содержимое нарушило ограничение безопасности или размера |
| `Failed` | обработка не завершилась; файл сохранён в `Errors`, если безопасное перемещение возможно |
| `Duplicate` | SHA-256 совпал с ранее обработанным файлом; новая копия не удалялась |
| `Reverted` | файл возвращён по исходному пути |

## ИИ и приватность

ИИ выключен по умолчанию. На вкладке **Настройки** задаются режим, размерный предел, названия моделей и месячный лимит обращений. Лимит считается по календарному месяцу UTC; каждый вызов провайдера расходует одну единицу, поэтому `Compare` резервирует сразу две. Для обращения к провайдерам настройте переменные окружения до запуска приложения. Секреты приложения в `settings.json` не сохраняются.

В **Форматы и приватные папки…** можно разрешить отправку для нужных семейств форматов и задать подпапки, которые всегда остаются локальными. По умолчанию разрешены текст/код, PDF и Office Open XML. Для визуального анализа PNG/JPEG/WebP отметьте отдельное разрешение на отправку самого изображения и включите семейство в список разрешённых. Отправляются только изображения размером до 12 МБ; для остальных форматов облаку передаются только разрешённые извлечённый текст и технические метаданные. Полный локальный путь не отправляется. Похожий на приватный ключ, токен или пароль текст блокирует отправку. Указание ключа включает возможность запросов, но не проверяет сеть и не гарантирует доступность или наличие средств у аккаунта.

В приложении уже есть локальный OCR с языковыми моделями `eng` и `rus`; сеть и отдельная установка Tesseract для обычной работы не нужны. Для его native-библиотек нужен [Microsoft Visual C++ 2015–2022 Redistributable x64](https://aka.ms/vs/17/release/vc_redist.x64.exe). Если компонент отсутствует или OCR завершается ошибкой, файл сохраняется для проверки. Для PNG/JPEG/GIF/WebP/BMP/TIFF/ICO встроенный OCR пропускает файлы больше 32 МБ или 12 мегапикселей. HEIF/AVIF оставляются для ручной проверки без OCR. Для сканированных PDF распознаются до 10 страниц без текстового слоя среди первых 40 страниц.

Если нужна другая сборка Tesseract или дополнительный язык, можно указать внешний движок:

```powershell
$env:FILE_SORTER_TESSERACT = 'C:\путь\к\tesseract.exe'
$env:FILE_SORTER_OCR_LANGUAGES = 'rus+eng'
```

Запустите приложение из того же PowerShell-сеанса, чтобы оно унаследовало переменные. `FILE_SORTER_OCR_LANGUAGES` по умолчанию имеет значение `eng+rus`; встроенные модели поддерживают только `eng` и `rus`, а внешний движок может использовать установленные у него языки.

## Локальный API и MCP

На вкладке **API и MCP** отображаются адрес API, read/write-токены и пример конфигурации stdio. API слушает только `127.0.0.1`; закройте приложение, чтобы остановить его. Одноразовые ссылки на загрузку и скачивание работают как bearer-capability: любой, у кого есть ссылка до истечения срока, может применить её один раз.

Не публикуйте токены, не вставляйте их в скриншоты и не пересылайте ссылки третьим лицам. Подробная таблица прав и маршрутов находится в [справочнике API/MCP](API_MCP.md).

## Папки и восстановление

Новые настройки, база, журналы, Inbox, Review, Quarantine и Errors располагаются в `%LOCALAPPDATA%\OptiumPlusFileManager`. Если там ещё нет профиля, Optium+ File Manager использует найденный предыдущий `%LOCALAPPDATA%\Optium`, `%LOCALAPPDATA%\OY_files` или `%LOCALAPPDATA%\FileSorterCollege`, сохраняя прежние настройки и историю на месте. Для результата используется сохранённый путь; стандартный новый путь — `Рабочий стол\OptiumPlusFileManagerData\Sorted`, затем проверяются существующие `Рабочий стол\OptiumData\Sorted`, `Рабочий стол\OY_filesData\Sorted` и `Рабочий стол\FileSorterData\Sorted`.

При аварийном завершении приложение сверяет записи `Moving` с зарезервированным путём и хешем при следующем запуске. Не удаляйте и не изменяйте файлы в этих папках до завершения восстановления. Если целевой файл изменён или путь занят посторонним файлом, запись остаётся для ручной проверки.

Для отдельного демонстрационного или диагностического профиля можно до запуска задать переменные окружения `FILE_SORTER_DATA_ROOT` и `FILE_SORTER_SORTED_ROOT`. Они перенаправляют настройки, базу, служебные каталоги и результат сортировки в выбранные папки; обычный запуск без этих переменных использует стандартные расположения.
