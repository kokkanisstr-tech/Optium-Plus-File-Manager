## Сценарии

Автоматизированный набор проверяет все 15 обязательных сценариев из раздела 14 `PROJECT_PLAN.md`, в том числе классификацию C# без расширения и Python в `.txt`, конфликт сигнатуры и расширения, ограничение памяти на большом файле, незавершённую запись, наблюдатель папки, дубликаты, конфликт имён, повреждённый PDF, опасный ZIP, локальный режим `Off`, отклонение некорректного ответа ИИ, низкую уверенность, точные правила имени, восстановление после перезапуска, отмену с проверкой SHA-256 и запрет записи read-only MCP-токеном. Новые сценарии поиска проверяют русскоязычный запрос с приоритетом C#, переход к другим папкам, пакетную проверку файлов свыше 16 кандидатов, сообщение об отсутствии файла, блокировку секретов/приватных файлов и изображений без разрешения, контракты всех трёх провайдеров (включая Gemini Interactions API с `store: false`) и отказ от ID, придуманного ИИ.

Дополнительно проверены REST read/write scopes, отказ отмены после изменения содержимого, запуск опубликованного exe как MCP stdio-сервера, атомарная квота, политика типов/приватных подпапок и отдельное разрешение оригинала изображения, действие «Не сортировать», метаданные PNG/WAV и схемы image/text запросов всех трёх HTTP-адаптеров на тестовых ответах. SQL-файл проверен на попадание в отдельную вновь созданную папку. Встроенный OCR распознаёт русский и английский в PNG и сканированном PDF; опасные размеры изображения пропускаются до декодирования. Данные тестов создаются в уникальных временных каталогах; обычные настройки и пользовательские файлы не используются.

Опубликованный exe открыт в рабочем Windows-сеансе: проверены тёмная тема, контраст вкладок и полей, дерево категорий с раскрытыми C#/Python/SQL и действия открытия/обновления. Review, история, настройки и API/MCP дополнительно проверены сборкой и интеграционными сценариями. Итоговая публикация дополнительно проверяется интеграционным запуском через MCP stdio.

## Непроверенные внешние условия

- Все три переменные `OPENAI_API_KEY`, `GEMINI_API_KEY` и `ANTHROPIC_API_KEY` отсутствовали. Контрактные HTTP-запросы проверены на поддельном обработчике; реальный запрос, доступность аккаунта и качество ответа не проверялись.
- REST и Streamable HTTP/MCP проверялись локально. Подключение к установленным пользовательским клиентам Antigravity, ChatGPT или Claude и их аккаунтам не проверялось.
- Для нативного OCR-движка нужен Microsoft Visual C++ 2015–2022 Redistributable x64; приложение и сортировка запускаются без него, а OCR при недоступности оставляет файл для ручной проверки.
- Живой вызов облачного провайдера остаётся обязательным внешним шагом раздела 16 исходного плана: нужен ключ, заданный локально в окружении пользователя.
