# Сценарий демонстрации на 5–7 минут

## Перед показом

- Опубликуйте `win-x64` сборку, создайте отдельную временную входящую папку и добавьте её в приложение.
- Оставьте облачный ИИ выключенным. Набор `demo/samples/` не требует ключей, сети или реальных документов.
- Для части про OCR требуется Microsoft Visual C++ 2015–2022 Redistributable x64. Без него пропустите этот показ: приложение оставит файл для ручной проверки.
- Скопируйте демонстрационные файлы в эту временную папку. Сканированный PDF и ZIP-примеры пересоздаются через `demo/CreateBinarySamples.ps1`.
- Убедитесь, что во входящей папке нет личных файлов. На экране API не показывайте токены и не копируйте их в запись демонстрации.

## Ход показа

| Время | Действие | Что показать |
|---|---|---|
| 0:00–0:40 | Открыть приложение, показать главную панель и вкладки | Автосортировка выключена по умолчанию; настройки и файлы остаются локальными |
| 0:40–1:30 | На вкладке Настройки показать отдельную входящую папку и режим локального анализа Off | Приложение не нуждается в API-ключах для базовой сортировки |
| 1:30–2:30 | Нажать Сортировать сейчас или включить автоматическую сортировку | `Батыр` определяется как C# без расширения, `.txt` с Python — как Python, `SQL-запрос.sql` — как отдельная категория SQL; целевые папки создаются автоматически |
| 2:30–3:20 | Обработать `Скан-конспект.pdf`, затем показать `Поддельное-изображение.jpg` и `Путь-с-выходом.zip` | Локальный OCR распознаёт русский и английский текст скана; сигнатура выявляет подмену JPG, а путь `../` не извлекается |
| 3:20–4:10 | Открыть `Нейтральная-заметка.txt` в Review, выбрать категорию и подтвердить | Неуверенное решение остаётся человеку; чекбокс сохраняет локальное правило по точному имени |
| 4:10–5:00 | Скопировать второй, изменённый текст с тем же именем и показать результат | Сохранённое правило применяется к следующему текстовому файлу с таким же именем; исходник не отправляется модели |
| 5:00–5:50 | Перейти в Историю, отфильтровать записи и экспортировать CSV | SQLite хранит историю; фильтры работают по статусу, категории, источнику и времени |
| 5:50–6:40 | Показать вкладку API и MCP, адрес `/mcp` и пример stdio-конфигурации | API ограничен loopback, read/write токены разделены, ссылки одноразовые |

## Короткое пояснение к примерам

- `Батыр`: расширение отсутствует, но содержимое содержит `namespace`, объявление класса и `Console.WriteLine`.
- `Python-в-текстовом-файле.txt`: расширение слабее синтаксических признаков `from` и `def`.
- `SQL-запрос.sql`: SQL-конструкции определяются по содержимому и направляются в `Programming/SQL`.
- `Задание-практика.txt`: в тексте встречаются слова про предмет, задание, лабораторную и студента.
- `Скан-конспект.pdf`: одностраничный PDF содержит только изображение с синтетическим текстом; встроенный OCR работает локально, без сетевых ключей.
- `Нейтральная-заметка.txt`: локальные признаки слабы, поэтому решение просит пользователя.
- `Поддельное-изображение.jpg`: это корректный пустой ZIP-контейнер под именем JPG; приложение не принимает его за изображение.
- `Путь-с-выходом.zip`: запись содержит `../outside.txt`; приложение не извлекает файлы из архива.

## Дополнительная часть про ИИ (по наличию ключей)

Если заранее настроены ключи двух провайдеров, можно временно выбрать `Compare` и повторно анализировать один безопасный демонстрационный текст. Покажите статус провайдера, результат и очередь Review при разногласии. Наличие ключа в интерфейсе не подтверждает доступность сети; не заявляйте измеренную точность без отдельного прогона и заполнения таблицы в [CLASSIFICATION.md](CLASSIFICATION.md).

Если ключей нет, оставьте режим Off и поясните архитектуру: локальная сортировка всё равно работает. Визуальный анализ фото включается только с отдельным разрешением на отправку PNG/JPEG/WebP до 12 МБ; приватные подпапки и файлы с вероятными секретами остаются локальными. Не вводите реальные API-ключи во время показа.

## Завершение

В конце можно открыть локальную папку `OptiumPlusFileManagerData/Sorted` и показать разные категории. Для обратного хода выберите в Истории завершённый пример и нажмите **Отменить перемещение**; приложение проверит SHA-256 и наличие исходного пути.
