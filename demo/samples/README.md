# Демонстрационный набор

Все примеры синтетические и не содержат реальных документов или секретов. Для показа скопируйте их в отдельную временную входящую папку, добавьте эту папку в **Настройки**, затем включите сортировку. Не используйте папку проекта как входящую.

| Файл | Ожидаемое поведение |
|---|---|
| `Батыр` | C# по содержимому без расширения; Programming / C# |
| `Python-в-текстовом-файле.txt` | Python по синтаксису, несмотря на `.txt` |
| `SQL-запрос.sql` | Programming / SQL; папка SQL создаётся при перемещении |
| `Задание-практика.txt` | Documents / Study по словам задания и лабораторной |
| `Скан-конспект.pdf` | локальный OCR читает английский и русский текст на сканированной странице; Documents / Study |
| `Нейтральная-заметка.txt` | низкая уверенность; Review |
| `Повтор-образец-A.txt`, `Повтор-образец-B.txt` | второй файл совпадает по SHA-256 и остаётся с состоянием Duplicate |
| `Поддельное-изображение.jpg` | валидный пустой ZIP с расширением JPG; конфликт формата попадает в Review |
| `Путь-с-выходом.zip` | содержит запись с именем `../outside.txt`; должен попасть в Quarantine, не распаковывается |

Сканированный PDF и бинарные примеры можно пересоздать командой из корня проекта:

```powershell
powershell -ExecutionPolicy Bypass -File .\demo\CreateBinarySamples.ps1
```

Порядок файлов влияет на то, какой из пары одинаковых текстовых примеров будет обработан первым. Существующий файл в `Inbox`, Review или Quarantine не удаляется автоматически.
